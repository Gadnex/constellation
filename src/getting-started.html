Constellation CSS prefers vendoring as a way of using the library. “Vendoring” software is a technique where you copy the source of another project directly into your own project.

Simply follow this link to find the original Constellation CSS file.

The minified version can be found here, but if you want to read and understand the CSS yourself, the unminified version may be better. You can always minify it along with your site's custom CSS.

Assuming your project exposes the CSS file at /css/constellation.css you can add the CSS file in your HTML as follows:

<link rel="stylesheet" href="/css/constellation.css">

Customizing

While you are free toc customize Constellation CSS as required, this may block you from upgrading to a more recent and improved version of the CSS.

With this in mind constellation has a number of CSS variables that can be set in a custom CSS file in your project that will override the most common look and feel options.

The following CSS can be used and customized with the interactive customizer below. 

:root {
    --brand: ;
    --color-degrees: ;

    --padding: ;
    --sidebar-padding: ;
    --box-padding: ;
}
