The switcher is a layout component to switch between two layout options. Either the inner elements are layed out side by side in a single row or they are layed out in a single column. This differs from the cluster in that a cluster can have multiple items on the same row, but also have multiple rows.

The switcher is applied by setting the layout-switcher attribute on an HTML element.

Modifiers

There are a number of additional layout modifiers that can be applied to a switcher to alter the appearence. Layout modifiers are applied as space separated values of the layout attribute. For example layout-switcher="40ch gap-1"

Gap

There are a number of layout modifiers to set the gap between the elements of the switcher. These are gap-{0-5}, which set progressively bigger gaps as the number increases. gap-0 means no gap at all. The default gap is gap-3.

There are also gap-r-{0-5} and gap-c-{0-5} modifiers that set only the row or column gap.

Threshold

There are a number of layout modifiers to set the threshold in ch units at which the switcher switches. These are {3-8}ch, which set progressively bigger thresholds as the number increases. The default threshold is 60ch.

CSS Variables

The following CSS variables are defined for the switcher.

--gap
Set the gap between the elements.
--threshold
Set the horizontal (inline) size at which the switched switches. Suggested to set the value in ch units. the default threshold is 60ch.
