The frame is a layout component designed for displaying image or video content within an HTML element. In sets a specific aspect ratio for the frame with a default value of 16 / 9.

The frame is applied by setting the layout-frame attribute on an HTML element.

Modifiers

There are a number of additional layout modifiers that can be applied to a frame to alter the appearence. Layout modifiers are applied as space separated values of the layout attribute. For example layout-frame="square"

CSS Variables

The following CSS variables are defined for the frame.

--aspect-ratio
Set the aspect ratio of the frame. It is recommended to use one of the CSS variables below as a value.
--ratio-ultrawide
Sets an aspect ratio of 18/5.
--ratio-widescreen
Sets an aspect ratio of 16/9. This is the default value.
--ratio-golden
Sets an aspect ratio of 1.6180/1.
--ratio-landscape
Sets an aspect ratio of 4/3.
--ratio-square
Sets an aspect ratio of 1/1.
--ratio-portrait
Sets an aspect ratio of 3/4.
