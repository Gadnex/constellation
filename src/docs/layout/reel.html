--- title: The reel pageOrder: 10 ---

The reel is a layout component designed for making an HTML element horizontally scrollable within its parent element.

The reel is applied by setting the layout-reel attribute on an HTML element.

Modifiers

There are a number of additional layout modifiers that can be applied to a reel to alter the appearence. Layout modifiers are applied as space separated values of the layout attribute. For example layout-reel="30vw gap-1"

Item width

There are a number of layout modifiers to set the width of the elements of the reel. The default item width is 20vw, which is 20% of the viewport (screen) width.

The examples below demonstare the different gap sizes.

Gap

There are a number of layout modifiers to set the gap between the elements of the reel. These are gap-{0-5}, which set progressively bigger gaps as the number increases. gap-0 means no gap at all. The default gap is gap-3.

The examples below demonstare the different gap sizes.

CSS Classes

There are a number of additional CSS classes that can be applied to a reel to alter the appearence.

Bordered

The bordered CSS class creates a border around the reel and sets block padding to create space between the border and the elements of the reel.

bordered

CSS Variables

The following CSS variables are defined for the reel.

--item-width
Set the width of the elements in the reel.
--gap
Set the gap size between the elements in the reel.
--reel-padding
Set the padding size below the elements in the reel where the slider resides.
--border-width
Set the border width when the CSS class bordered is applied.
--border-color
Set the border color when the CSS class bordered is applied.
