--- title: The container pageOrder: 13 ---

The container is a layout component that is applied to an HTML element that creates specific behaviours of the container element and its decendents, depending on the width of the container.

The specific width is 60ch. Some bahaviours occur when the width is more than 60ch and other behaviours occur when the width is less than 60ch.

CSS Classes

There are a number of additional CSS classes that can be applied to a container to alter the appearence and behaviour.

Mobile show and hide

There are a number CSS classes to show or hide content inside a container on mobile screens.

mobile-show
Only shown on mobile
mobile-hide
Hidden on mobile

Grow and no-grow

There are a number CSS classes to grow or not grow flexbox content inside a container on mobile screens.

These CSS classes work on child elements of the fullscreen, stack, cluster, sidebar, switcher and reel layouts, which are all implemented using CSS flexbox.

The grow class will set the flex-grow: 1; flexbox property on the element. The grow-fast class will set the flex-grow: 999; flexbox property on the element, which will make the element grow faster than other elements with the grow class.

There are also mobile-grow and mobile-no-grow classes available. These are implemented using CSS @container queries and are applied when the closest ancestor layout-container element is less than 60ch wide. If there is no ancestor layout-container element, then the ancestor layout-fullscreen is used for the @container query.

mobile-grow
Grown on mobile
grow + mobile-no-grow
Not grown on mobile
