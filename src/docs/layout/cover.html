The cover is a layout component designed for vertically centering the contents within an HTML element.

It has been decided not to implement the cover as the stack with layout modifier v-center can achieve the same layout. Please note that you still need to set the height of the layout-stack.

The cover is applied by setting layout-stack="v-center" on an HTML element.

Horizontally centered

If you want to center the content of an element both vertically and horizontally you can apply the layout-stack attribute with the v-center and h-center modifiers to the element.
