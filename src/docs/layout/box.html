--- title: The box pageOrder: 2 ---

The box is a layout component designed for placing a number of HTML elements inside a box that is visually distinct from the backgrount it is placed on. The box has some padding to ensure the content of the box does not touch the border.

The box can be visually styled with a background color, border and a border radius.

The box is applied by setting the layout-box attribute on an HTML element.

CSS Variables

The following CSS variables are defined for the box.

--box-color
Set the font color of text in the box.
--box-background-color
Set the background color of the box.
--box-border-radius
Set the border radius of the box. It is suggested to use the --size-{1-12} CSS variables to have a responsive border radius.
--box-padding
Set the padding of the box. It is suggested to use the --size-{1-12} CSS variables to have a responsive padding size.
--border-width
Set the box border width in px. Not suggested to use the size responsive variables here.
--border-color
Set the border color of the box when the utility class shadowed-glow is applied
--glow-color:
Set the glow color for dark mode when the utility class shadowed-glow is applied.
